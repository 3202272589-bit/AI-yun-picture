# 🌌 AI 智能云图库 (AI-Yun-Picture)

## 📖 项目介绍

**AI 智能云图库** 是一个基于前后端分离架构的企业级云端图片管理平台。该平台不仅提供了基础的图片上传、管理和分享功能，还创新性地融入了**AI 图像处理（AI扩图）**、**以图搜图**、**颜色搜图**以及**多用户实时协作编辑**等高级特性。

系统支持灵活的**空间管理**（个人空间与团队协作空间），并提供细粒度的权限控制与多维度的空间数据可视化分析。在架构层面，后端采用分库分表技术与高性能无锁队列（Disruptor）以应对海量图片数据与高并发协作场景，致力于打造一个高性能、高可用、智能化的图片资产管理方案。

---

## ✨ 核心功能

### 👤 用户模块
* **用户认证与授权**：支持用户注册、登录，基于 Sa-Token 实现鉴权。
* **角色管理**：普通用户、管理员角色划分，支持后台用户管理。
* **VIP 体系**：支持会员兑换码（Vip Code）功能，不同等级享有不同空间容量与特权。

### 🖼️ 图片管理模块
* **多模式上传**：支持本地文件上传、URL 网络图片抓取上传、批量图片上传。
* **图片处理**：内置图片裁剪（ImageCropper），支持按比例、自定义尺寸裁剪。
* **图片搜索**：
    * **多条件检索**：支持按名称、标签、分类等基础检索。
    * **以图搜图**：基于图像特征的相似图片检索（集成第三方识图/阿里云服务）。
    * **颜色搜图**：基于主色调的图片精准检索。
* **批量操作**：支持对图片进行批量编辑、分类与管理。

### 🤖 AI 与智能增强
* **AI 扩图 (Out-Painting)**：集成阿里云 AI 接口，支持对残缺或小尺寸图片进行智能延展与补全。
* **智能标签与分类**：上传时自动提取图片特征，生成推荐标签。

### 🗂️ 空间管理模块
* **个人空间**：用户专属的私有图片存储空间，具有容量与等级限制。
* **团队空间**：支持多用户加入同一空间，共享图片资产。
* **空间权限 (SpaceUser)**：细粒度的团队空间角色权限控制（如浏览者、编辑者、管理员等）。
* **空间数据分析 (Space Analyze)**：提供丰富的可视化图表，包括：
    * 空间使用量分析
    * 图片分类/标签词云分析
    * 图片大小分布分析
    * 用户上传排行榜

### 🤝 实时协作模块
* **多端同步编辑**：基于 WebSocket 实现的图片状态实时同步。
* **协作并发控制**：在团队空间中，支持多人对同一图片的协同编辑状态广播。

## 🛠️ 技术栈

### 💻 前端技术 (Frontend)
* **核心框架**：Vue 3 + Composition API
* **构建工具**：Vite
* **开发语言**：TypeScript
* **状态管理**：Pinia
* **路由管理**：Vue Router 4
* **网络请求**：Axios / OpenAPI 自动生成代码
* **实时通信**：WebSocket (原生/库封装)
* **代码规范**：ESLint + Prettier

### ⚙️ 后端技术 (Backend)
* **核心框架**：Spring Boot 3 / Java
* **持久层框架**：MyBatis-Plus
* **数据库**：MySQL 8.x
* **缓存与分布式**：Redis (用于缓存、分布式 Session、限流等)
* **权限认证**：Sa-Token (轻量级 Java 权限认证框架)
* **对象存储**：腾讯云 COS (Cloud Object Storage) 或阿里云 OSS
* **分库分表**：Apache ShardingSphere (动态分表路由，应对海量 Picture 数据)
* **高性能队列**：LMAX Disruptor (用于处理高并发下的 WebSocket 实时编辑事件)
* **第三方服务集成**：阿里云 AI 图像处理接口 (AliYun AI)

## 🏗️ 架构亮点

1.  **动态分表架构 (Dynamic Sharding)**：随着平台图片数据量的不断增长，单表性能可能遇到瓶颈。项目引入了 ShardingSphere，针对图片表(`Picture`)实现了基于特定算法的动态分片路由，保障了大数据量下的查询与写入性能。
2.  **高并发协作处理**：在 WebSocket 实时图片编辑场景下，多用户的高频操作可能引发竞态条件。后端创新性地引入了 **Disruptor 高性能无锁内存队列** (`PictureEditEventDisruptorConfig`) 来异步化、顺序化地处理编辑事件，极大提升了吞吐量并保证了数据一致性。
3.  **细粒度团队权限控制**：基于 Sa-Token 实现了基于团队空间资源的方法级/注解级权限校验 (`@SaSpaceCheckPermission`)，安全可靠地隔离了不同租户/团队之间的数据。
4.  **灵活的色彩处理引擎**：后端自主实现了颜色转换与相似度计算算法 (`ColorTransformUtils`, `ColorSimilarUtils`)，使得基于主色调的图片搜索功能兼具高性能与高准确率。
